# Калькулятор рентабельности тендеров (Кыргызстан)

Веб-калькулятор для участников государственных закупок Кыргызской Республики: показывает, до какой цены можно снижаться на торгах, чтобы контракт оставался прибыльным.

**Сайт: https://zakupi.vercel.app**

Интерфейс на кыргызском и русском языках. Все данные хранятся только в браузере (`localStorage`), сервера и регистрации нет.

## Возможности

- **Параметры тендера** — плановая сумма закупки, себестоимость товаров, логистика, гарантийное обеспечение (в процентах или фиксированной суммой), прочие расходы.
- **Налоговые режимы** — единый налог 0%, 0,5%, 1%, 2%, 4%, 6%; общий режим (НДС 12% с зачётом входящего НДС, налог с продаж 1%, налог на прибыль 10%); произвольная ставка от выручки или от прибыли.
- **Симулятор снижения цены** — ползунок от 0 до 40% и точное поле (до 99,99%, с сотыми долями) с мгновенным пересчётом цены контракта, налогов, чистой прибыли и рентабельности.
- **Обратный расчёт** — по желаемой рентабельности показывает максимально допустимое снижение и минимальную цену.
- **Точка безубыточности** — максимальное снижение и минимальная цена, при которых прибыль не уходит в минус.
- **Матрица чувствительности** — таблица показателей при разных процентах снижения.
- **Спецификация товаров** — редактируемая таблица, сумма которой может автоматически подставляться в себестоимость.
- **Импорт и экспорт** — загрузка спецификации из Excel и CSV, выгрузка полного расчёта в `.xlsx`, шаблон для заполнения.
- **Печатный отчёт** — карта рентабельности тендера для печати или сохранения в PDF.
- **Сохранённые расчёты** — до 50 тендеров с названиями: сохранить текущий, загрузить, перезаписать или удалить.
- **Ссылка на расчёт** — кнопка «Поделиться» копирует ссылку, по которой коллега откроет тот же расчёт (данные передаются в самой ссылке, на сервер ничего не отправляется).
- **Готовые шаблоны** — примеры тендеров: оргтехника, продукты питания, стройматериалы.

## Важно

Расчёт носит справочный характер и не заменяет консультацию бухгалтера. Ставки и правила расчёта налогов заданы в `src/utils/taxCalculator.ts` — перед использованием сверьте их с действующей редакцией Налогового кодекса КР.

Все суммы вводятся и рассчитываются в сомах. В режиме RUB результаты пересчитываются по курсу, который вы вводите сами; актуальный курс приложение не загружает.

## Запуск локально

Нужен Node.js 20.19+ или 22.12+ (требование Vite 8).

```bash
npm install
```

```bash
npm run dev
```

Приложение откроется на http://localhost:3000.

Остальные команды:

| Команда | Что делает |
| --- | --- |
| `npm run build` | Собирает production-версию в папку `dist` |
| `npm run preview` | Запускает собранную версию локально |
| `npm run lint` | Проверяет типы TypeScript |
| `npm test` | Запускает автотесты (Vitest) |

На каждый pull request и push в `main` GitHub Actions автоматически проверяет типы, запускает тесты и сборку (`.github/workflows/ci.yml`).

## Технологии

React 19, TypeScript, Vite, Tailwind CSS 4, SheetJS (`xlsx`) для работы с Excel, иконки `lucide-react`, тесты на Vitest.

## Структура проекта

```
src/
  App.tsx                 состояние приложения и сохранение в localStorage
  components/             блоки интерфейса (параметры, симулятор, таблица, отчёт)
  utils/taxCalculator.ts  расчёт налогов, прибыли и точки безубыточности
  utils/excel.ts          импорт и экспорт Excel / CSV
  utils/storage.ts        проверка данных из localStorage и список сохранённых расчётов
  utils/share.ts          ссылка на расчёт
  utils/currency.ts       пересчёт сумм в рубли
  utils/__tests__/        автотесты расчётов, импорта, хранения и ссылок
  __tests__/App.test.tsx  автотесты интерфейса (Testing Library)
  data/defaultTemplates.ts  готовые шаблоны тендеров
  i18n/translations.ts    тексты на кыргызском и русском
```
